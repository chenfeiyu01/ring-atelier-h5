# 实现与公开方案调研

调研日期：2026-10-09。

- [Three.js](https://github.com/mrdoob/three.js)：持续维护的 MIT 渲染库，支持 WebGL / WebGPU。项目使用锁定的 0.180.0 WebGL 版本与路径追踪器配合。
- [three-gpu-pathtracer](https://github.com/gkjohnson/three-gpu-pathtracer)：持续维护，MIT。调研时主线已转向 WebGPU；本项目锁定 0.0.24 的 WebGL 路线，以覆盖更多 H5 浏览器。精细模块动态载入，桌面加载后启用，手机默认使用实时模式。
- 对扭转戒圈、环形圆珠槽模型进行了定向公开检索，未找到足够匹配且可直接复用的模型；改为 Blender 参数化建模。没有购买或下载收费模型。

## 结构决定

模型采用一条有封闭底托和两条槽沿的连续槽带，截面沿周向完整旋转 360 度。开放面与封闭背面一起转动，所以在不同位置分别朝向戒圈内侧、外侧或前后方。银白圆珠沿中轴环绕排列，共 26 颗。

这次明确移除了错误的固定圆筒内衬。金色主体是单个封闭网格，背面是圆顺的宽曲面，两条唇边带细小倒角；槽的几何开口只有一侧。模型使用 640 段周向采样，珠子使用 64×32 球面分段。`scripts/validate_model.py` 针对当前翻转截面验证，不再使用普通圆筒内壁的假设。

没有真实指围、原始 CAD、材质或灯光文件。珠子数量、槽深、截面和隐藏区域属于根据视频推断的视觉重建参数。几何检查通过不能代替与原片的视觉验收。

## 渲染

- 自生成线性 HDR 摄影棚环境，高精度曲面与 PBR 金属材质，ACES 色调映射。
- 六次光线反弹。静止时每帧一个完整样本，最终累计到 192 样本，直接对路径追踪器的原始完整分辨率纹理使用原有 DenoiseMaterial（sigma 2、threshold 0.14）。静止输出不经过运动滤波器。
- 移动时仍进行路径追踪，dynamicLowRes 的预算由 26 万提高到 48 万像素，缩放范围 0.4–1。只计算运动缓冲，避免同时计算完整缓冲。松手约 65ms 开始完整积累；保留取消惯性尾段与 1×1 采样的调度优化。
- 根据当前深度还原世界坐标，再投影到上一帧。材质编号、世界法线与位置一致时复用历史；新显露或遮挡发生变化的表面重新计算。换灯光、尺寸或画质时清除历史；重新分配后先初始化两侧颜色和深度缓冲，再绑定为采样输入，避免空的几何缓冲导致运动画面变黑。
- 使用三次插值采样历史纹理，避免重复双线性重采样使高光变软。历史可靠的表面直接累计未模糊样本，短历史区域只用小范围 3×3 几何过滤。局部颜色范围限制与视角变化权重用于抑制过期反射和拖影。显示前只做约一像素的边缘保留过滤以减少残余颗粒；这一结果不写回历史，避免模糊逐帧积累。
- 静止积累结果持续写入历史，下一次拖动从已有清晰画面开始。静止最终显示保持独立，不受历史过滤或截断影响。192 样本之前仍有渐进改善，运动中的每帧并不等于离线高采样图像。
- 像素比上限 1.8、总像素上限约 220 万；页面隐藏时暂停。

时序积累方向参考 [NVIDIA 的时空重建研究](https://research.nvidia.com/labs/rtr/publication/schied2017spatiotemporal/)；实际实现位于 src/motion-denoise.js，并针对当前静态珠宝几何和相机移动编写。

## 视觉复核

网页实图保存在 `docs/qa/`。首版界面概念图仅作布局参考，最终几何以视频和补充截图为依据。

| 检查项 | 当前结果 |
| --- | --- |
| 深色摄影棚、戒指主视觉 | 保留，背景统一为黑色 |
| 右侧控制区、标题比例 | 桌面显示完整；390 px 宽时转为下方控制区 |
| 圆珠和戒圈厚度 | 已加粗，26 颗圆珠，避免初版细链比例 |
| 内外翻转、单侧开放 | 已重建为整条带底托的槽一起翻转 |
| 金属明暗和互反射 | 桌面精细模式路径追踪，银珠可反射金色槽壁 |

仍然存在的视觉差异：原片的准确截面、珠子数量、金色高光位置和银珠反射形态不能从现有压缩视频唯一还原。当前版本是可交互外观重建，不能标注为原款精确复刻或与 KeyShot 原片一致。

画质复核（2026-10-09）：恢复 192 样本后，与用户认可的早期静止截图在相同 1280×720 视口、相同相机角度下对照；最终显示重新使用相同的原始路径追踪纹理与去噪器。快速往返拖拽、缩放和持续旋转已检查，银珠的明暗反射在运动中保留。最新截图与运行指标见 docs/qa/README.md。旧版 refinement-speed.json 中 48 样本的 1.1–1.4 秒完成时间不适用于当前 192 样本版本。
