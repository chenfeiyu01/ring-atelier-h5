## 2026-10-25 补充：微动首帧与首饰部件间反射

在第一版实时预览 `cbc1b8b` 上继续改进：补充不透明首饰的一次近场反射，使用约 2.4 万 / 4.8 万像素的独立预算、求交代理和深度引导重建；主显示几何、宝石光学与最终 192 样本保持完整。照明改用带柔边的有限柔光箱，避免整片上半球同亮造成银珠的白圆片外观。

专项检查实际执行按下指针、移动 1 像素并保持按下：样本归零，显示模式为 preview，历史权重为 1；继续转动后权重降为 0。换金属后历史立即失效。相同微动视角分别与各自 192 样本图比较，前景区域 8-bit RGB 平均绝对误差由 21.13 降到 3.59，RMSE 由 45.30 降到 8.53。这是首帧连续性的图像对照，不是物理准确度或主观真实感评分；新版灯光也有变化。

Apple M4 / Chrome 155，1280×900、848×776 画布，同样的连续输入轨迹：四爪钻石成对 GPU 均值 9.94 → 9.93ms，RAF 间隔 16.64 → 16.65ms。增强后的槽带在多次测量中约 3.0–3.6ms；三线款在当前负载下没有稳定达到 60 帧，GPU 计时波动明显，不将单次数字当作稳定加速结论。新计算有固定预算，不以降低最终静态采样量获取画质。

交互与布局的 13 项回归检查通过。最终生产包另行验证正常扩展、禁用 Float32 线性过滤扩展两种情况，完成加载、拖动、192 样本、暖光及蓝宝石。390×844 DPR 2 触控模拟验证了三线 / 槽带切换、微动首帧历史权重约 0.99、持续转动权重归零及静态恢复，没有横向溢出。上述检查没有应用错误或警告。

首帧历史只用于很小的相机变化，并通过真实几何深度排除遮挡不匹配；持续大角度运动仍由有限反射近似承担，细小反射会比静态求解柔和。当前没有发布到 GitHub Pages。Safari 和实体手机的性能、发热与视觉效果仍未验收。

## 2026-10-25 实时珠宝预览与静态路径追踪

本轮以 `9faf0bf` 为基线，在 Apple M4、Chrome 155、1280×900 窗口、848×776 实际画布上对照。以下为本机单次测量，受缓存和设备影响，不作为手机性能保证。

| 指标 | 原实现 | 当前实现 |
| --- | ---: | ---: |
| 连续拖动每帧 GPU 平均耗时 | 15.85ms | 9.08ms |
| 连续拖动每帧 GPU P95 耗时 | 21.71ms | 12.30ms |
| 首次可操作时间（缓存复测） | 2.31s | 0.45s |
| 松手至完整 192 样本 | 2.98s | 3.10s |

GPU 使用 `EXT_disjoint_timer_query_webgl2` 包围查看器每次 RAF 工作，分别得到 133 / 174 个有效查询；输入为相同的连续指针轨迹。优化后拖动时全场景路径追踪帧增量为 0，宝石每帧确定性计算三波段。完整静态采样时间没有明显缩短，改善来自稳定的实时画面与提前解锁，而非降低最终采样量。

实时场景中，宝石实例化并合并同材质金属后，四爪 / 三线 / 槽带分别为 3 / 4 / 2 次绘制，不含最终全屏输出。相较同一预览器未合并金属时的 53 / 263 / 21 次绘制明显减少；这些数字不与原路径追踪的一次全屏调用直接比较。

通过 13 项浏览器检查：首帧先于收敛显示、192 样本后停止绘制、拖动与按住输入期间不追踪、四种金属、三种镶嵌、三套灯光、三种视角、三种戒托、缩放、键盘与重置、反复切换后的资源稳定性、390×844 DPR 2 触控模拟及 embed。没有应用错误、警告或失败请求。

生产包 `npm run build` 与 `vite preview` 另行验证首帧、拖动、完整细化、暖光及蓝宝石；模拟禁用 `OES_texture_float_linear` 后同样通过。原 HDR 环境与追踪器生成的 Float32 背景改用最近邻过滤，避免该条件下不完整纹理。

本轮没有发布到 GitHub Pages。Safari WebDriver 因本机未启用“允许远程自动化”而无法执行；实体 iPhone / Android 的性能、发热和视觉效果仍需验收。下文此前“只运行精细模式”“首次等待 192 样本”等描述属于对应日期的历史实现，当前行为以本节和实现说明为准。

## 2026-10-10 初次光影优化与 20 颗钻石的历史测量

以下实测来自当前 Mac，不是所有设备的速度保证；窄屏模拟不代表实体手机性能。

| 模式 | 16 样本 | 完整 192 样本 | 画布缓冲 |
| --- | ---: | ---: | --- |
| 优化前银珠 | 0.36 秒 | 4.22 秒 | 848×574 |
| 最终银珠 | 0.27 秒 | 2.42 秒 | 848×575 |

桌面窗口为 1280×720。新增镶嵌控件使画布高度增加 1 像素，最终相机有相应微小差异；此前同画布、同相机的优化隔离对照是 4.22 → 2.31 秒。所有当前结果保留 192 样本和完整输出分辨率。钻石具有额外折射、全反射与色散计算，不能把银珠完成时间当作钻石时间。
