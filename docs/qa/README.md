# 验证记录

2026-10-09，在当前 Mac 的 Codex 浏览器内完成。窄屏测试不是实体手机测试。

## 当前画质恢复与时序重建

- 恢复原来的 192 次静止采样、原始完整分辨率纹理和 DenoiseMaterial 参数；静止最终显示绕过运动滤波。与此前认可的 192 样本截图在相同 1280×720 窗口、相同相机下进行了对照。192 样本仍有随机采样差异，不能声称逐像素完全相同。
- 取消运动时两遍大范围模糊。改为世界坐标重投影、深度/法线/材质一致性检查、历史累积与三次插值。运动预算从 26 万增加到 48 万追踪像素。
- 窄屏复核发现直接显示历史会保留过多颗粒，因此显示前增加约一像素的边缘保留过滤；过滤结果不写回历史，避免模糊反复积累。运动历史在慢速转动时的诊断保留比例约 99%，诊断读回代码已移除。
- 实际检查了连续旋转、快速往返拖拽、缩放及运动中换灯光。银珠反射条纹保留，没有观察到明显残影；快速转动和新显露的表面仍可能有少量采样噪点。
- 桌面开发记录：1280×720 窗口、848×597 缓冲，实际拖拽松手后 16 样本约 0.35 秒、32 样本约 0.72 秒、完整 192 样本约 4.55 秒。这个结果不是所有设备的保证。静止恢复后持续进行背景细化，不能继续使用上个 48 样本版本的“一秒完成”描述。
- 运动期间路径追踪和历史帧计数增加，普通渲染计数维持 1（初次加载）。环境切换、画质切换与尺寸变化会清除历史。
- 修复尺寸变化后的历史缓冲初始化：原始追踪仍有像素但法线/深度缓冲为空时，会使运动画面变黑。现在显式初始化两侧缓冲后才绑定为着色器输入，已在 390×844、默认窗口和 1280×900 间切换复测。
- 390×844 窗口没有横向溢出；缩小、恢复窗口后画面正常。此项只验证桌面浏览器的窄屏布局与缓冲重建，不代表实体手机性能。
- 最终构建通过。正式预览在 5187；构建资源逐一核对与 dist 一致。控制台未见 error/warn。

当前证据：`temporal-quality.json`、`temporal-final-static.png`、`temporal-mobile-moving.png`、`temporal-rapid-drag-zoom.png`、`temporal-moving-light-change.png`、`production-assets.json`。
