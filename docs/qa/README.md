# 验证记录

## 当前版本：2026-10-10 光影优化与钻石

以下实测来自当前 Mac，不是所有设备的速度保证；窄屏模拟不代表实体手机性能。

| 模式 | 16 样本 | 完整 192 样本 | 画布缓冲 |
| --- | ---: | ---: | --- |
| 优化前银珠 | 0.36 秒 | 4.22 秒 | 848×574 |
| 最终银珠 | 0.27 秒 | 2.42 秒 | 848×575 |
| 最终钻石 | 0.51 秒 | 6.08 秒 | 848×575 |
| 钻石窄屏模拟 | 0.33 秒 | 3.98 秒 | 388×443 |

桌面窗口为 1280×720。新增镶嵌控件使画布高度增加 1 像素，最终相机有相应微小差异；此前同画布、同相机的优化隔离对照是 4.22 → 2.31 秒。所有当前结果保留 192 样本和完整输出分辨率。钻石具有额外折射、全反射与色散计算，不能把银珠完成时间当作钻石时间。

钻石内部额外遍历从 20 调整为 12 后，当前视角完整采样约 7.37 → 6.08 秒。并排检查保留切面明暗和内部反射；抽样钻石区域平均亮度低约 1.1%，图像差异也包含随机采样噪点。保留一般反弹 8 次，没有再降低最终样本数。对照见 `diamond-path-budget-comparison.png` 和 `diamond-and-refinement.json`。

## 已完成的检查

- 桌面 Chromium：银珠 / 钻石切换、拖拽、缩放、重置、灯光、正面与侧面预设；切换后旧几何和历史缓冲不残留。运行时保持路径追踪，普通渲染计数为 0。
- 390×844：画布 388×443，页面宽度和滚动宽度均为 390；钻石完整显示，新镶嵌选项可用。实际鼠标拖拽、换灯光、切回银珠和重置通过。
- 桌面 Safari：实际发现并处理钻石通用透射发黑；改用抛光介质采样后，钻石内部反射、拖拽、暖金光、切回银珠和缩放可见。钻石模式关闭可触发联合着色器问题的金属清漆层；切回银珠在非 Apple WebKit 引擎恢复原参数。
- 钻石几何：57 个光学切面与 16 个腰棱面；网格封闭、正体积、凸，光学面平面误差小于 1e-6；20 颗均无金色戒托表面相交，邻石包围球最小间距约 0.01437。见 `../diamond-validation.json`。
- 原戒托和 20 颗银珠模型未改动，沿用 `../model-validation.json` 的当前几何结果。
- JavaScript 语法检查和生产构建通过。当前资源采用相对地址，适用于 GitHub Pages 项目子目录。构建由 `.github/workflows/pages.yml` 发布。

当前数据：`diamond-and-refinement.json`。当前画面：`diamond-final-drag.png`、`diamond-mobile.png`、`diamond-safari-warm.png`、`silver-safari-final.png`，以及发布后的最终截图。

## 已知边界

快速转动和刚显露的表面仍可能存在采样颗粒；钻石火彩随视角变化，不以稳定不变的贴图代替。三波段色散是光学近似。实体 iPhone Edge、Android 的触控、性能和发热尚未验证。浏览器测试不代表原片精确复刻或最终用户视觉验收。
